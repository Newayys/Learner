# Learner

## Anciens sujets SI Banque PT (2003-2012)

Ajoutés depuis banquept.fr, rubrique « Annales d'annales » (rubrique23.html), 30 épreuves.

- `Allpdf/BPT_SI{A,B,C}_AAAA.pdf` : un PDF par épreuve. De 2006 à 2012, le site les distribuait en .zip de plusieurs fichiers ; ils sont fusionnés dans l'ordre sujet → annexes / documents ressources → documents réponses / cahiers → calques → erratum. Les rendus ont été comparés page à page aux originaux (identiques).
- 2003-2004 : les épreuves s'appelaient Sciences Industrielles I, II, III ; elles sont rangées en SIA, SIB, SIC (champ `epreuve_originale`).
- 2003-2005 et plusieurs pages 2006-2012 (polices sans table d'encodage) sont des scans ou du texte illisible : texte obtenu par OCR (champ `texte_ocr`).
- `Alljsons/` : même format que les autres sujets, avec des champs en plus par question, ignorés par le site :
  `page` (page du PDF fusionné), `texte` (début de l'énoncé, 1 200 caractères max), `tags` (mots-clés technologiques libres : ressort, rondelles ressort / ressorts plats, roulements, étanchéité, fonderie / moulage, soudage, précharge…).
- Classification : relue question par question (énoncé lu, 1 à 3 thèmes par question), uniquement dans les thèmes déjà présents sur le site. Faute de catégorie « Conception », les questions de dessin et de choix de solutions sont rangées surtout en « Dimensionnement : Liaisons mécaniques » (et fonderie, soudage, forgeage en « Procédés : Métallurgie et traitements thermiques »). Le découpage en questions suit la numérotation du sujet (champ `decoupage_questions`) ; pour 2009 SI A, il se fait par sous-partie.
- `Textes/BPT_SI*_AAAA.txt` : texte intégral de chaque PDF fusionné, page par page (`===== page N =====`), OCR compris, pour la recherche plein texte.
- `Rapports/` : rapports de jury de l'écrit SI 2003-2014 (non reliés au bouton « Corrigé »).
